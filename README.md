# Simple chess engine

My own realization of chess game logic

## How to use
You can clone this project and use Chess_board class

## It heve 2 main fuctions for game:

- get_moves() which returns all posible moves from one color
- play_turn() which receive one of the moves
then return game`s satus and chess notation
**Warning! play_turn() can't performe 2 moves in a row from one color**
